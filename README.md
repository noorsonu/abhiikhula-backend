# AbhiiKhula

Initial Spring Boot monolithic project setup.

- Java: 21
- Spring Boot: 3.5.5
- Build: Maven
- Database: PostgreSQL
- Database name: abhiikhula_db
- Database username: postgres
- Server port: 8080

Create the PostgreSQL database `abhiikhula_db`, then open the project in IntelliJ IDEA or STS and run `AbhiiKhulaApplication`.

No business modules, entities, repositories, services, or APIs have been added yet.
